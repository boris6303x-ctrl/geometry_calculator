This is a calculator that calculates the areas and perimeters of 7 shapes: a rectangle, a circle, a right triangle, an isosceles triangle, a square, a rhombus, and a regular hexagon. It is calculated using geometric formulas. It can even draw shapes using the turtle module! The forward() function is drawn using a centimeter constant. It ignores all Pycache files with .gitignore. It is ideal for mathematicians and Python teachers. In addition, it is ideal for learning the classes in Python and two modules: math and turtle.
